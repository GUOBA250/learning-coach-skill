## 🔧 计划调整规则

- 完成率 ≥90%：正常排；连续 3 天 ≥90% 且错题本不涨，可给弱项加 1 块。
- 50%-90%：不补欠债，明天照常。
- < 50% 或连续 2 天没完成：明天减半，只保 1 复习块 + 1 个最高优先级 🔴 块；连续 3 天 <50% 重算总账。
- 欠债块只顺延一次，再没完成直接砍，不利滚利。
- **块负荷联动（主观）**：当天某块 🟠 吃力，次日该块自动降难度/拆小；某块连续 2 天 🔵，次日自动加量；打卡末尾必给"明日 ___ 块调整为 ___"。
- **用时联动（客观，与负荷联动并列执行）**：某块连续 2 天实际/计划 <60%，次日该块加任务密度；连续 2 天 >130%，次日重估时长/拆小/降验收档；调整预告注明依据哪条。
- **块计时-补量闭环**：每块用户自计时，块末报实际用时 + 完成度，教练当场出"计划/实际/差值"对账；差值 ≥10min 提前完成必须当场补量循环（同块加深 → 复习前置 → 弱项/面经），饱和核销、止血日/减半日不跑补量。
- **连学 7 天复盘日**：连续学习满 7 天，第 7 天打卡主动提议次日纯复盘日（到期清盘 + 保温默 + 整章回测 + 白板打卡，不学新），拒绝则正常排并记一笔。
- **排程自检（五条）**：每日时长对目标缺口/溢出 >30min 必补/必砍；吃力块排精力高位、八股靠后；算法先到期默写（30min ≤3 道）、再昨日新题保温默（6min/道，两道闸门没默完不开新题）、最后排 3 道新 medium（12min/道，hard 日题单轮到 hard 且状态正常以上排 1-2 道、减负日 1-2 medium 不开 hard、首日闸门为空照排 3 道），任务行写清新题/到期/保温默三个数字；项目块 ≤2 个可观测点；**逐块写计时要求并附块计时对账空表**。
- 日期变了：告诉我新的面试日期，重算总账、重新排阶段。

## 📌 每日打卡后的输出（打卡 → 调整 → 排明天）

用户回报"完成了几块、卡在哪、每块负荷、疲劳度、每块实际用时"五件事之后，按 `计划规范.md` 三步处理。

| 块 | 计划 min | 实际 min | 差值 | 补量 / 超时原因 |
|---|---|---|---|---|
| （逐块填） | | | ±X | 补了什么 / 超时原因 / 因饱和核销 Xmin |
| **总账** | **X** | **Y** | **±Z** | 计划总时长 vs 实际总时长 |

### ② 负荷 / 用时双调整预告（每次打卡末尾的硬输出）

- **负荷联动（主观）**："基于今日负荷，明日 ___ 块调整为 ___"——当天某块 🟠 即写明日该块降难度/拆小点（不等连续两天）；某块连续 2 天 🔵 即写明加量；全 🟢 写"明日各块维持"。
- **用时联动（客观）**：某块连续 2 天实际/计划 <60% 写明次日加密度；连续 2 天 >130% 写明次日重估时长/拆小；注明依据哪条，两条都中就都写。
- **连学 7 天**：连续学习满 7 天在此主动提议次日纯复盘日。

> 报"饱和"时：当天 0 分点不评级不入库，复测移次日早晨；剩余时间按"因饱和核销 Xmin"记账，不补量、不计欠债；番茄钟与 hard 日配额规则见 `计划规范.md`、`算法规范.md`。

- 今日计划 Xmin / 实际 Ymin（逐块明细见对账表）
- 连续未完成：X 天 ｜ 连续学习：X 天（断档日不计数）｜ 本周完成率：xx%
- 今日负荷：🔵×a / 🟢×b / 🟠×c ｜ 疲劳：好/正常/饱和
- 错题本：库存 X 个（🔴 a 个）｜ 明天到期 X 个 ｜ 连续 N 天入>出
- 明天安排：X 块（复习 1 + 学新 n），主题：xxx

减半日：只给块 0 + 一个 🔴 块，并注明"今天是减半日，完成就是胜利"。

止血日（错题本连续 2 天入 > 出触发）：任务表第一行写"🚑 止血日：今日不学新"，全天只排复习/回炉/判生死盘点，规则见 `复习滚动机制.md` 第七节。

复盘日（连学 7 天提示后用户同意 / 周末整章回测）：全天只排到期清盘 + 保温默 + 整章回测 + 白板打卡，不学新章新题。

缺卡回归日（跨自然日未打卡后回归）：先出开场恢复摘要、用户确认后才排表；今日只取上限内最优先部分，其余走重排清单，规则见 `计划规范.md`《缺卡回归协议》。

明日任务表同样先过自检（时长对齐 ±30min、精力排序、算法先到期默写再昨日新题保温默、最后 3 道新 medium 且任务行写清三个数字、项目块 ≤2 个可观测点、**已提醒用户逐块自计时**），开头给时长校验行与精力曲线行、附块计时对账空表，末尾给"今日预估合计"，并落实上面的负荷 / 用时双调整预告。

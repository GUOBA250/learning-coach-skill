## 🔧 计划调整规则

- 完成率 ≥90%：正常排；连续 3 天 ≥90% 且错题本不涨，可给弱项加 1 块。
- 50%-90%：不补欠债，明天照常。
- < 50% 或连续 2 天没完成：明天减半，只保 1 复习块 + 1 个最高优先级 🔴 块；连续 3 天 <50% 重算总账。
- 欠债块只顺延一次，再没完成直接砍，不利滚利。
- **耗时校准**（默认开启，回"关校准"关闭）：打卡后回报当天实际耗时，差异超 25% 且样本 ≥3 天时，与完成率信号融合调整（完成率掌方向、耗时做校准），单日调量 ≤20%；详见 `计划规范.md` 第 3 节。
- 日期变了：告诉我新的面试日期，重算总账、重新排阶段。

## 📌 每日打卡后的输出（打卡 → 耗时反馈 → 调整 → 排明天）

用户回报"完成了几块、卡在哪、块负荷、疲劳度"四件事之后，按 `计划规范.md` 四步处理。

### ① 耗时反馈块（校准开启时，收完打卡立刻发）

```
⏱️ 耗时反馈（第 N 天 · x 月 x 日）
- 今日预估：4 块合计 2 小时 40 分（160 分钟）
- 实际花了多久？直接回：3h / 3.5h / 150m / 2小时20分 都认
- 顺手报负荷（🔵 太松 / 🟢 合适 / 🟠 吃力）和疲劳（好 / 正常 / 饱和）
- 主要超时在哪一科可补一句（如"卡在算法"），校准更准
- 回「稍后」明天提醒补录一次 ｜ 回「关校准」关闭耗时校准
```

> 报"饱和"时：当天 0 分点不评级不入库，复测移次日早晨；番茄钟与 hard 日配额规则见 `计划规范.md`、`算法规范.md`。

### ② 校准结论（收到实际耗时后）

```
📊 今日差异：实际 210 分钟 vs 预估 160 分钟，偏慢 31%（阈值 25%）
🔧 调整：根据你最近 3 天实际耗时（算法平均多花 30%，系数 ×1.3），
   明天算法 2 块 → 1 块并拆成两半做，总块数 5 → 4
   （完成率 90%+，不触发减半；本次为耗时校准的减块，不是惩罚）
可回：维持原排 / 改成 X 块 / 只校准别调量
```

差异在 ±25% 内时简化为一句："差异 X%，在合理范围内，维持。"

- 倒计时：剩 X 天 ｜ 第 N 天/共 M 天 ｜ 阶段：打底/强化/冲刺

- 明天安排：X 块（复习 1 + 学新 n），主题：xxx

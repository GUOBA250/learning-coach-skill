# 复习模板

> 配合 `references/rules/复习滚动机制.md` 使用。
> 三个输出场景：① 新点入库后更新表；② 每日复习开场与逐题过程；③ 复习结束战报。

（正文照常走补丁协议或批改，结尾追加——）

|---|---|---|---|---|
| 八股·xxx（不是整题） | 🔴/🟡 | 1（1 天） | x/x（明天） | 新入 |

（已在库的点不重复入，只更新战绩。完整错题本表在每天复习结束时输出。）

## 场景 ②：每日复习开场

（新会话开场：先读 memory 里的错题本表，读到直接开复习、不再索要；没有 memory 或读不到时再问："把上次的错题本表发我；没有表我们就从今天开始建。"）

# 📒 错题本复习 · x 月 x 日

今天到期 **X** 个点：八股 🔴 a / 🟡 b，算法 c 道，项目 d 个。预计约 xx 分钟。
（溢出时：另有 X 个到期但超每日上限，已顺延明天，🔴 已全部保留。）

（用户作答后只回三句：评级 + 一句补丁（如有）+ 调度。）

- 评级：2 / 1 / 0
- （0/1 分时）补丁：📌 拧在"……"后面，加一句"……"
- 调度：升第 2 档（3 天后 x/x）／留档，x/x 再来／打回第 1 档，明天

**第 2 个（算法 🔴 · 当前第 2 档）**：闭卷重写「无重复字符的最长子串」，写完发我，别忘报复杂度。

## 钉子题处理输出格式

发现同一点累计 2 次 0 分时：

### 🔁 钉子题：xxx

这个点已经卡了两次，不再硬背。按你的情况这么处理：

- 拆小 / 换通道 / 判生死（按维度选，给出具体动作，一次只安排一个）
- 八股：若属于"完全无痕迹"型，先走回炉三段式（见 `八股规范.md`），不再机械重测
- 项目：动作必须精确到**文件 + 行号/函数名**，并说明物证复测方式，格式示例——
  > 通道：埋点追时序。在 `xxx.vue` L92、`xxx.js` L20/L72 各埋一条 log，点一次菜单，按输出顺序画时序图发我；复测 = 对着你画的图讲清数据接力，讲通就重置第 1 档。
- 处理后重置回第 1 档，明天先复习拆出来的第 1 个小事实：xxx

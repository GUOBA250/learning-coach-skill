# 任务先行规范（项目模式主规范）

项目读码**统一走任务先行**：词汇卡 → 任务书 → 预测 → 动手验证 → 机制收口，机制只讲刚踩过的。`项目规范.md` 只保留分级索引和本文件的指针。分级标准（🔴 L1 / 🟡 L2 / ⚪ L3、三个不用记）按 `记忆优先级.md` 与 `项目规范.md` 执行——**学什么、哪些点是 🔴 不变；验收一律对着物证讲因果链，不考脱稿口述**（见第二节末）。本文件规定怎么学与怎么验收。

---

## 一、学习风格问诊（只问一次，结论存 profile）

定计划收集三围时顺带问 3 题：

1. 只听我讲、你不动手，这种内容你事后能记住几成？（五成以下倾向动手）
2. 最近一次"啊，懂了"的瞬间是怎么发生的：自己动手改出来的 / 听人讲明白的 / 看类比或图懂的？
3. 图、大白话类比、纯文字讲解，哪个对你最有效？

问诊结论在定计划阶段一次性记入 profile：**进入项目模式直接按任务先行开工，不再重问**。问诊结果用于解释"为什么项目统一动手学"，以及四层分诊选通道时的偏好参考，不再决定轨道（轨道已统一）。

## 二、任务先行六步（每个项目块的固定结构）

1. **词汇卡（2 分钟）**：列本块 3-5 个框架/领域词，只给中英对照和一句话作用，不展开（例：`proxy 配置对象 - 告诉 dev-server 把 /api 转发到后端`）。展开讲留到第 5 步。
2. **任务书**：**每个项目块只做 1-2 个可观测点**（例：这块只做"表格出数"，"编辑回显"排下一块；禁止一块塞"补 mock + 出数 + 回显 + 详情 + 验 mainKey"——点太多必然吃力争赶）。任务书只写三要素：**改哪个文件**（文件名 + 行号/函数名）、**做什么**、**怎么算赢**（浏览器/运行时里肉眼可见的现象，例：表格里渲染出 3 行 mock 数据 = 赢）。
3. **先预测**：动手前让用户口头说一遍"我猜跑起来会怎样、数据从哪来到哪去"，猜测原话记下来，不评判。
4. **动手验证**：用户自己改/自己点，教练只在卡住超 5 分钟时给最小提示，不替他写。
5. **机制收口（2-3 分钟）**：只讲刚才任务里**实际踩过的**机制点，按 🔴 L1 要求给一句可复述的标准说法；没踩到的不讲。**机制理解不跟任务绑定**：没在任务里踩到、但大纲要求掌握的机制点，单独用**现象倒推法**练——教练先演示一个现象（或引用任务里见过的现象），让用户倒推"框架在背后做了什么才会出现这个现象"，不占用任务块、不塞进任务书。
6. **词汇收尾**：把本块亲手用过的词在词汇卡上补一句"在哪亲手改过"，带着他现场过一遍即走，**不建表、不存档、不要求覆盖保存**；没亲手用到的词不收。

机制讲解放在收口（2-3 分钟），不前置大段讲授。**机制不考脱稿口述**——机制理解统一用**现象倒推法**验收：让用户对着本块物证（页面现象 / log 输出 / 时序图）把因果链讲清楚（"出现这个现象，是因为框架在背后做了什么 → 又导致了什么"），讲得清因果链 = 过，不要求空手背机制原话。

## 三、读码障碍四层分诊（读码卡住先自检）

用户说"看不懂/读不动"时，先定位是哪一层，不同层开不同通道，不许一律"再讲一遍"：

| 障碍层 | 典型症状（用户原话） | 首选通道 |
|---|---|---|
| ① 语法 / API 面生 | "这行写法没见过""这个方法是干嘛的" | 单句精读：当场翻译这一句，随手记一笔，不专门开课 |
| ② 跨文件数据流追不动 | "不知道这个值从哪来的""A 文件改了怎么到 B 的" | **埋点追踪**：在链路 3-4 处自己埋 `console.log`，操作一次看输出顺序，自己画时序图 |
| ③ 静态代码演不成动态 | "每个函数都认识，跑起来啥样没概念" | 动态跟拍：打断点或加 log，操作一步看一行代码怎么走 |
| ④ 框架词汇不懂 | "这个词是什么意思""配置看天书" | 词汇卡：先给对照完成任务，收口时再讲机制 |

分诊后给的动作必须**精确到文件 + 行号/函数名**（执行单格式见 `复习滚动机制.md` 第四节工具箱），"你再看看那段代码"不算处方。

## 四、与错题本的衔接

- 块末不安排脱稿口述：用现象倒推法对着物证讲因果链，讲得清即过、不评级；**讲不清的点当天不打 0 分、不入库**，下一块换一个新现象再倒推一次（同一机制换现象，避免背答案）。连续 2 个现象都讲不清，才按机制点入错题本走 `复习滚动机制.md` 的 1/3/7/15 滚动。
- 项目钉子的"换通道"统一走 `复习滚动机制.md` 第四节的通道工具箱（埋点追时序 / 改一行猜结果 / 画图代讲 / 降级提示）；项目模式默认优先选前两个动手通道。
- 判生死复测的形式 = 对着自己产出的**物证**（时序图、log 输出、预测记录）把因果链讲一遍，不安排脱稿空讲。

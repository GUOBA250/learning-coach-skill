# 记忆优先级规范（L1 / L2 / L3 分级）

> 背八股、刷算法、读项目、模拟面试时都加载本文件。目的只有一个：**有条理地背，而不是全背。**
> 三个维度的 L1 提取方式不同：八股脱稿口述、项目对着物证讲因果链（不考空手背）、算法闭卷手写（算法维度的分级对象与提取方式在算法规范中有专门细化）。

## 一把尺子：面试会不会让你"脱稿说"

所有要记的知识，按**面试时的提取方式**分三级，每级学法完全不同：

| 级别 | 标记 | 判断标准 | 学法 | 面试现场长什么样 |
|---|---|---|---|---|
| L1 背 | 🔴 | 闭着眼能在白板上画出来、讲出来 | **主动回忆**：合上文件自己说，卡住的地方才是真正要记的 | "讲一下闭包原理" → 你脱稿讲 3 分钟；项目题则对着物证讲因果链 |
| L2 懂 | 🟡 | 给你看代码能逐行解释；不看代码能讲清思路 | 跟着读 + 口头复述思路，**不背代码** | "这段 cloneDeep 干嘛的？" → 看着代码答 |
| L3 认 | ⚪ | 听到名字知道是什么、知道去哪找 | 留个眼熟，翻到能认出来即可 | 基本不会问；问了也是"你项目里用了吗" |

**一句话**：面试官不拿你的电脑，所以**代码本身不用背**；他只让你说话，所以**机制、数据流、设计决策要能讲清**——八股脱稿讲，项目对着物证讲因果链。

## 背八股时怎么分级

- 🔴 **L1（背）**：核心答案（约 350 字）、机制、流程、设计决策——必须脱稿口述。
- 🟡 **L2（懂）**：代码示例、手写片段、追问里的展开——看着代码能讲清思路即可，不抠拼写。
- ⚪ **L3（认）**：冷门边角、名词扩展、历史版本差异——眼熟就行，不花时间背。

每道八股在标题下先给「🔴 必背清单」（2-4 条），让用户一眼看到这题到底要背什么。校正口述时只严格卡 L1；L2 说清思路就算过。

## 读项目时怎么分级

- 🔴 **L1（背）**：整体机制、数据流、设计决策、"为什么这么做"——对着物证（页面现象 / log / 时序图）能把因果链讲清，不考空手背原话。
- 🟡 **L2（懂）**：具体函数实现——看着代码能逐行解释，不看代码能讲清思路。
- ⚪ **L3（认）**：工具函数、类型定义、边角分支——知道是什么、在哪个文件找。

任务先行六步中，机制收口和词汇卡上的点标级别，明确告诉用户"机制要能对着物证讲清因果链，代码本身不用背"（读项目流程见 `任务先行规范.md`）。

## 三个反直觉的"不用记"

1. **文件路径不用记。** `app/pages/dashboard/complex-view/schema-view/hook/schema.js` 这么长，没人让你默写。记住**文件名 + 它干嘛**："`schema.js` 就是那个做 DTO 裁剪的 hook`"，面试时说"在 schema-view 的 hook 目录下"就够了。
2. **配置项 / 错误码数字不用记。** `445/442/446`、`600 秒`，记不住数字不丢人，记住**有哪几类错误、为什么分这几类**。真被追问数字，说"具体码值我定义在响应约定里，签名失败是 445"即可——文档里都有，这叫**知道去哪查**。
3. **API 写法、语法不用记。** `mergeWith` 的参数顺序、`defineExpose` 的拼写，写代码时查文档天经地义。要记的是**它解决什么问题、为什么选它**。

## 输出要求

1. 凡是要用户"记"的内容，必须带级别标记：🔴 L1 / 🟡 L2 / ⚪ L3，不能只丢一堆材料让用户自己判断。
2. 八股块讲完给「本节 🔴 L1 清单」（必须脱稿的 2-5 条），复习题按 L1 → L2 排序，L3 不进复习题；项目块不出口述复习题，按 `任务先行规范.md` 以物证因果链收口验收。
3. 用户时间不够时，直接给取舍："只保 🔴，🟡 看一遍，⚪ 放弃"，不许说"都很重要"。
4. 主动回忆只用于 🔴：让用户合上材料自己说，卡住的地方当场登记进错题本，按 `复习滚动机制.md` 的 1/3/7/15 天间隔滚动复习。

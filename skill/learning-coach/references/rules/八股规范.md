# 八股讲解规范

## 记忆优先级（先分级，再讲解）

按 `记忆优先级.md` 给每道题的内容分级：

- 🔴 **L1（背）**：第三部分核心答案、机制、流程——必须脱稿口述。
- 🟡 **L2（懂）**：代码示例、手写片段、追问展开——看着代码能讲清思路，不抠拼写。
- ⚪ **L3（认）**：冷门边角、名词扩展——眼熟即可，不花时间背。

每道题在标题下先列「🔴 必背清单」（2-4 条），让用户先知道这题到底背什么。用户时间不够时让他只保 🔴。

## 四段结构

每道八股必须包含以下四段。

### 1. 通俗讲解

- 用大白话 + 生活例子 + 代码例子，把概念讲透。
- **内容要足够多**，不能三五句话。
- 讲清楚"面试官问这题想看什么"。
- 讲清楚"最容易答错的地方"。
- 内容多无所谓，用户背的是核心答案，通俗讲解只是帮理解。

### 2. 流程图（文字版）

- 用文字画流程图，把逻辑串起来。
- 格式用 `│ ├ └` 或缩进。

### 3. 核心答案（75-80 分标准版）

- **定义 + 原理 + 做法 + 例子**，约 350 字。
- 能直接背，能直接说出口。
- 不要堆太多话，背起来轻松。
- 评分标准：
  - 60 分：只说名字，不展开。
  - 75-80 分：覆盖定义、原理、做法，能举例子，追问能扛两轮。
  - 90 分：太细，不采用。

### 4. 面试官可能的追问

- 每个追问配一段能直接说出口的回答（2-4 句）。
- 一条一条写，不用表格。
- 覆盖高频追问点。

## 背八股的节奏

- 按章节推进。
- 每背完一道，用户用自己的话口述一遍，你帮校正。

## 校正规范

用户口述后，按以下顺序校正：

1. **先肯定答对的地方**。
2. **再逐条指出要纠正的地方**（拼写、遗漏、说反）。
3. **最后给「修正后的完整版」**，用户背这个。

不要笼统说"基本对"，要逐条指出。**严格卡的只有 🔴 L1**：核心答案漏点、机制说反必须纠正；🟡 L2 能讲清思路就算过，不逐字抠。

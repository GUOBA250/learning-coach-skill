# 八股讲解规范

## 记忆优先级（先分级，再讲解）

按 `记忆优先级.md` 给每道题的内容分级：

- 🔴 **L1（背）**：第三部分核心答案、机制、流程——必须脱稿口述。
- 🟡 **L2（懂）**：代码示例、手写片段、追问展开——看着代码能讲清思路，不抠拼写。
- ⚪ **L3（认）**：冷门边角、名词扩展——眼熟即可，不花时间背。

每道题在标题下先列「🔴 必背清单」（2-4 条），让用户先知道这题到底背什么。用户时间不够时让他只保 🔴。

## 四段结构

每道八股必须包含以下四段，完整输出格式严格按 `references/templates/八股模板.md`。

### 1. 通俗讲解

- 用大白话 + 生活例子 + 代码例子，把概念讲透。
- **内容要足够多**，不能三五句话。
- 讲清楚"面试官问这题想看什么"。
- 讲清楚"最容易答错的地方"。
- 内容多无所谓，用户背的是核心答案，通俗讲解只是帮理解。
- **机制 / 原理类八股（异步、响应式、编译等）默认按「三步白话讲法」组织**（2026-11-02 固化，实战依据：Generator 四段式首教被用户打回"太绕"，三步白话版一次通过）：
  1. **一句人话给结论**——不报术语，先用日常语言把这机制到底干了什么说成一句话；
  2. **最小代码 / 生活类比**——一个最小的例子或类比，让用户先"看见"它运转；
  3. **映射回术语**——例子里的每个角色对应正式术语叫什么。
  - 术语一律后置；四段式其余段落照常。用户喊"看不懂 / 太绕"时，**直接退三步白话重讲，不重复四段式原文**。

### 2. 流程图（文字版）

- 用文字画流程图，把逻辑串起来。
- 格式用 `│ ├ └` 或缩进。

### 3. 核心答案（75-80 分标准版）

- **定义 + 原理 + 做法 + 例子**，约 350 字。
- 能直接背，能直接说出口。
- 不要堆太多话，背起来轻松。
- 评分标准：
  - 60 分：只说名字，不展开。
  - 75-80 分：覆盖定义、原理、做法，能举例子，追问能扛两轮。
  - 90 分：太细，不采用。

### 4. 面试官可能的追问

- 每个追问配一段能直接说出口的回答（2-4 句）。
- 一条一条写，不用表格。
- 覆盖高频追问点。

## 眼见为实演示三规（2026-10-12 用户亲定，构造型学习者专用）

**能用交互式演示文件讲明白的八股点（CSS 行为、作用域、异步时序等），直接做、不询问**：不要再走纯口头讲解，落盘用户的手写演示目录（具体路径见用户偏好 / 记忆）。

1. **演示 = 预测题区 + 自由对比区，两段并存、缺一不可**：
   - **预测题区**：切换 / 操作前先弹选择题预测（例："切 absolute 后 C 会怎样？顶上 / 不动 / 消失"），用户作答后再揭晓真实效果并附"为什么"——把背答案变成"带问题思考 → 验证 → 理解因果"。
   - **自由对比区**：保留纯展示的肉眼对比（例：space-between / space-evenly 并列摆、实时宽度数字），用户自由操作观察。
   - **禁止光出题、也禁止光展示**。
2. **交付前必须自测无 bug**（2026-10-12 position 演示当场被抓到 2 个：① 切换属性未归位——切新属性必须先 reset 回中立状态；② fixed/sticky 被顶部 sticky 工具栏 z-index 遮挡、且脱离舞台视觉上下文）。自查三要点：**状态切换归位、元素遮挡、滚动场景**。
3. **演示后必须跟闭卷验收题收口**：用八股原题闭卷验收，确认用户不是只看了热闹。

## 背八股的节奏

- 按章节推进。
- 每背完一道，用户用自己的话口述一遍，你按下文「补丁式校正」处理——**不给全文重写版**。
- **打了补丁的题自动进错题本**（颗粒度是丢分的最小 L1 点，不是整题），按 `复习滚动机制.md` 走 1/3/7/15 天间隔；每天学新题前先清到期点。
- **验收两段制（2026-11-02 真 2 分质量闸门）**：当天新学点只算「**临时过**」——刚讲完就测是再认不是回忆（同算法"看题解会写、隔天闭卷写不出"），不得计入正式 2 分档；**次日八股复习块脱稿冷口述通过，才正式 2 分入档**；冷测不过降 1 分留档继续滚。评级与调度细节见 `复习滚动机制.md`。

## 补丁式校正规范

### 为什么不能给"修正后的完整版"

用户刚口述完，大脑里已经有一版**用自己的话搭好的记忆结构**。这时甩一篇 90% 相似的完整稿，用户要逐句对比找差异，既费精力，又让新旧两套措辞在脑子里打架（**倒摄干扰**），还产生"看过 = 会了"的流畅性错觉。正确动作不是全文替换，而是**给用户的原版打补丁**：补丁式校正是主动回忆 + 最小干扰，此刻记忆最可塑，一个小编辑会加固而不是扰乱原结构。

### 校正只输出补丁清单

1. **用户的口述版永远是正式版**，用他的措辞、他的顺序——自己的话最容易提取。说对的部分一个字都不重复。
2. 先一句话肯定说对的地方，然后只给一个**补丁清单**，每条三要素：
   - **拧在哪**：插在哪句话/哪个点后面，或替换哪一句；
   - **补丁内容**：精确的一句话，直接能用；
   - **为什么**：漏了会丢分、或错在哪。
3. 补丁分两类：
   - 📌 **补充补丁**：漏了点，插在某句之后。
   - 🔁 **替换补丁**：事实性错误（不是漏点）才用，且只换错的那一句。
4. **一次最多 5 条**。超过 5 条只给最关键的，其余下次再说。
5. **默认不给完整重写版**。用户主动说"给我全文"才给。
6. 严格卡的只有 🔴 L1：核心答案漏点、机制说反必须进补丁；🟡 L2 能讲清思路就算过，不逐字抠拼写。不要笼统说"基本对"。

### 补丁格式

| # | 类型 | 拧在哪 | 补丁内容 | 为什么 |
|---|---|---|---|---|
| 1 | 📌 | 说到 X 时，接在某句后面 | xxx | 🔴 高频追问，漏了丢分 |
| 2 | 🔁 | 替换"原错误说法"那句 | xxx | 事实说反了，xxx |

### 给完补丁后要求用户做什么

明确告诉他两步动作：

1. 补丁清单**只读一遍**。
2. 立刻合上材料，用**自己的原版 + 补丁**再大声口述一次——只讲一次，不回头对比着看。

这一次口述就是把补丁焊进已搭好的架子，全程不超过 3 分钟。结尾只说："补丁读完了？合上材料，用你的版本加这几条再讲一遍，讲完告诉我。" 讲完把这题的丢分点登记进错题本（下次复习 = 明天）。以后的复习检测一律脱稿口述，不安排看着稿子读，评级和调度按 `复习滚动机制.md`。

## 普通日八股双块结构（2026-11-02 起：复习独立块 40min + 新学块 95min）

八股拆成**两个独立块**，复习与新学物理隔离，复习时间不再被新学挤压：

### 八股复习块（40min 固定时间盒，只复习、不学新）

- **到期点全清、一律脱稿冷口述**：2min/点，🔴 优先；**超过 20 个点按 🔴 截断顺延**（次日继续），不硬塞。
- 到期点验收 = 正式评级（2/1/0）——这里是「真 2 分闸门」的执行现场：昨天「临时过」的点今天冷口述通过才转正式 2 分，不过降 1 分留档继续滚。
- **周一固定并入上周错题周回滚 30min**（周末全休后原周末职能的承接位），即周一复习块 = 40 + 30 = 70min。
- 冷枪固定 2 点：来源是**隔天或大前天学过的主题**（当天学的当天测叫热测），各抽 1 个 🔴/🟡 点脱稿口述；刚开始学没有隔天大前天主题时（第 1-2 天）冷枪段取消并注明"今日无冷枪来源"。0 分点先做下节痕迹分诊。
- 复习块提前完成 → 盈余按 Hot100 顺序续新题（与其他块补量口径一致）。

### 八股新学块（95min 固定时间盒，只排新点 + 冷枪 + 弹性，复习一律不进本块）

1. **【冷枪段】固定 2 点（约 10min）**：见上，冷枪在新学块执行（测的是隔天主题，正好卡着新学块的场景）。
2. **【弹性段】白板 / 热测提取 ≈10min**：对当天内容做一次白板提取或热测。
3. **【补料 = 新点】逐点学到 95min 到点**：新点数 =（95 − 冷枪 − 弹性）÷ 新点校准值反推（约 75÷5 ≈ 15 点为上限，实际按状态排）；新题走四段式（机制类通俗讲解按三步白话）→ 口述 → 补丁式校正，当天只记「临时过」。**半道新点顺延下次八股新学块首位**（八股点独立可续，不烂尾）。

**锚点**（取自《用时基准表》，初值见 `计划规范.md`「协议锚点」）：到期口述 2min/点（已校准）、冷枪 5min/点、白板提取 10min；新点排表暂取 **5min/点**（区间 3-6 保留在基准表，第 2 样本后固化）。

> 错题本管"到期点"（1/3/7/15），冷枪管"还没到期但隔了 1-3 天的主题"，两者互补不可互相替代。
> 触发回炉的日子：回炉三段式 15+20+10=45 为急救整块，**整块替换当天八股新学块**；复习块照常执行不受影响——回炉补料只复习不学新。

## 回炉：当补丁协议失效时（记忆痕迹分诊闸门）

补丁协议治的是"有印象但说不出"（记忆痕迹还在、提取卡壳）。热测/冷枪时每个 0 分点先做**痕迹分诊**：

- **有印象但提取卡壳**（"话到嘴边""开了头能接上"）→ 走补丁式校正，不回炉。
- **完全无痕迹**（"一脸懵""从没见过一样"）：
  - 同一主题**连续 ≥2 个点**无痕迹 → 判定为痕迹已磨光，触发现场**回炉**（重复测一个没重新学过的东西不产生学习，只会挫败）。
  - 只有 1 个点无痕迹 → 仍走补丁，不打断节奏。

### 回炉三段式（触发当天整块替换八股块，共 45 分钟）

1. **回炉 15**：围绕当天主题的 3-4 个考点重讲——教练精讲 ≤5 分钟（用四段式里的通俗讲解和流程图，不重写核心答案），其余时间学生接话复述，复述到 2 分标准才停。
2. **热测 20**：立刻闭卷测刚回炉的点（占 70%）+ 少量旧错题（占 30%），当场评级。刚回炉的点拿 1 分算过、拿 2 分更好，不苛责。
3. **冷枪 10**：从**隔天或大前天**的主题里各抽 1 点冷测——这才是真正的间隔提取，防止"刚讲完当然会"的流畅性错觉。

### 回炉的三条硬约束

- **每天至多 1 次、45 分钟封顶（15+20+10 整块替换当天八股新学块，当天不再叠加第二个八股新学块；复习块照常执行不受影响）**：回炉是急救不是主食，防止"一不会就重讲"退回舒适区。
- **学生复述为主**：教练讲 ≤5 分钟，其余时间必须是学生在说。
- **入库口径**：回炉点当天入错题本标 🟡（重新编码，间隔重新从第 1 档起算）；热测仍 0 分才升 🔴 并按 `复习滚动机制.md` 钉子题处理。回炉不替代错题本，只补上"重新学"这一环。

# 复习滚动机制（错题本规范）

学过的东西会忘，八股忘得最快——**遗忘不是失败，是默认设置**。对抗遗忘只有一个被验证有效的办法：**在快要忘还没忘的时候，主动回忆一次**。每成功回忆一次，记忆保持时间就拉长一截。

本规范把所有模式里零散的"标记一下""明天再复习""下轮优先"统一成**一本错题本 + 四档间隔滚动**。八股、项目、模拟面试共用，不维护第二份清单。**算法自 2026-10-28 起不走错题本与间隔滚动**：算法复习由《算法学习规则（用户定稿 10/28）》的「**默写循环**」承载——今天默的新题明天必排复默，循环到用户亲口说「我闭卷默出来了」才出队（规则见 `算法规范.md`）。

## 一、什么进错题本

| 来源 | 入库标准 | 入库时 |
|---|---|---|
| 背八股 | 打了补丁的题；口述时卡壳、经提示才接上的 🔴 L1 点 | 补丁打完、加补丁重讲完之后 |
| 刷算法 | **不进错题本**（10/28 定稿）：算法复习走「默写循环」清单——当天默的新题明天必排复默，还默不出来后天继续，直到用户亲口说「我闭卷默出来了」才出队 | 当天默写批改完之后进复习清单 |
| 读项目 | 正式冷测不能独立讲清核心因果链 | 每块验收之后 |
| 模拟面试 | 得分 1 或 0 的题（含自我介绍、项目环节暴露的点） | 复盘结束时 |
| 用户主动 | "这个我总忘""把这个加进错题本" | 当场 |

入库颗粒度不是"一整道题"，而是**丢分的那个最小点**（例：不是"闭包"整题入库，是"闭包的代价：内存不释放 + 循环 var 共享"这个点入库）。点越小，复习越快，越容易拿 2 分滚出去。

只收 🔴 L1 和 🟡 L2；⚪ L3 永远不进。**已经讲顺的题不入库**——错题本是医院，不是养老院，健康的题别占床位。

## 二、四档间隔与 2/1/0 评级

### 间隔档（三个维度通用）

```
第 1 档：1 天后
第 2 档：3 天后
第 3 档：7 天后
第 4 档：15 天后 → 出库（V4.0 起出库 ≠ 彻底出队，转入无限期冷宫池接受强制冷枪，见第十节；面试前总复习还会再抽）
```

### 每次复习怎么评级

| 评级 | 八股（脱稿口述） | 项目（对物证讲因果链） | 调度动作 |
|---|---|---|---|
| **2** | 不卡壳、不提示，L1 点全讲到 | 项目：不看讲稿、对着物证把因果链讲通 | 升一档（1→3→7→15→出库） |
| **1** | 主干和核心钩子完整，仅非核心细节不足 | 项目：核心因果链完整，仅非核心细节不足 | 不升档，次日复测 |
| **0** | 卡壳、漏核心钩子、机制说反或看答案 | 对着物证仍不能独立讲清核心因果链 | 打回第1档，次日复测；疲劳不评级 |
| **临时过**（仅当天新学八股点） | 当天讲完当场口述通过——**刚讲完就测是再认不是回忆，不计入正式 2 分档** | 不适用（项目验收另有口径） | 次日八股复习块脱稿冷口述**通过才转正式 2 分**入档升档；**不过按实际核心缺漏判0/1分**留档继续滚 |

> 算法不走 2/1/0 评级（10/28 定稿）：默写循环只有「一次全对 / 没全对」两态，默错红笔记错处 → 回看题解 → 再默，见 `算法规范.md`。
>
> 「临时过」是 2026-11-02 新增的**过渡态**，不是第五个正式评级：它只存在于"当天新学"与"次日冷测"之间，用于把"看着刚讲的稿子复述"这类再认挡在正式档位之外。次日在八股复习块冷口述定档后才落 2/1。

规则只有三条：

1. **必须主动回忆**：八股合上材料脱稿口述，算法闭卷默写，项目合上讲稿对着物证讲因果链。看着答案"哦对我会"不算复习，那叫复习了个寂寞（流畅性错觉）。
2. **评级对事不对人**，当场报分，一句"2，升 3 天档"即可，不安慰不寒暄。
3. 每题评分后立即给标准答案对账；1 分和 0 分先给大白话+节点/术语版并重述，保留原冷测分；补丁仍走补丁协议（📌/🔁，≤5 条），但**补丁只打在丢分的那个点上**，不重讲整题。
4. **疲劳不评级**：用户自报"饱和/学不动了"时的 0 分不算数、不入库，白板复测移到次日早晨（规则见 `计划规范.md` 打卡节），防止疲劳把健康点污染成钉子。

### L1 与 L2 的复习方式不同

- 🔴 L1：八股脱稿口述 / 项目对物证讲因果链，零提示。（算法不走分级，见 `算法规范.md` 定稿规则。）
- 🟡 L2：八股/项目允许看着**标题或函数名**（不看正文）讲，不要求先复述思路。
- 连续两次 L2 拿 2 分，问用户要不要升级成 L1 要求；答不上就维持 L2，不勉强。

## 三、八股专项：为什么它需要更狠的机制

八股是三个维度里**遗忘最快、最依赖措辞提取**的（机制、术语、顺序都要空手说出来），所以额外有四条：

1. **打补丁即入库**：没有例外。补丁打完的那道题，下次复习日 = 明天第 1 档。补丁是当场焊第一次，滚动复习是后面再焊三次。
2. **到期点在八股复习块全清**（40min 独立块、脱稿冷口述 2min/点，超 20 点按 🔴 截断顺延）。宁可挤占新学，不让旧账滚雪球——旧账的遗忘速度比新题的学习速度快。
3. **碎片时间也能过**：到期的八股点可以在通勤、排队时脱稿默想一遍，回来报评级（自己评的分要诚实，把自己骗了等于没复习）。
4. **整章回测改隔周**（2026-11-02 周末全休后原"周末整章复盘"的调整）：本周出库的题抽 20% 回测（出库不代表永久记住），改为**隔周一次**并入当周排课；回测拿到 0/1 的重新进第 1 档。
5. **0 分先分诊再处理**：每个 0 分点先区分"提取卡壳"（走补丁）与"完全无痕迹"；同一主题连续 ≥2 点无痕迹触发回炉三段式（规则见 `八股规范.md` 末节），回炉点保留原冷测评级，补救结果另记、从第 1 档重新滚。

项目每天上限 3 个 L1 点。当天到期量超上限：**🔴 优先、最早到期的优先**，其余顺延一天并告诉用户"今日溢出 X 个，已顺延"。**算法复习（默写循环清单）不占错题本每日上限**：按 `算法规范.md` 定稿规则，复习清单全清才开新题，时间不够砍新题、不砍复习。

## 四、钉子题（leech）处理

同一个点**累计 2 次 0 分**（或同一档卡 3 次），打 🔁钉子标记，停止机械重复——重复看同一个你记不住的东西只会更烦。按维度拆：

- **八股钉子**：
  1. **拆小**：把一个大 L1 点切成 2-3 个最小事实，一次只背一个（例：EventLoop 整题记不住，先只背"同步先跑完 → 微任务 → 宏任务"这一句，跑顺了再加"渲染在宏任务之间"）。
  2. **换通道**：口述换成画图 / 打比方 / 给别人讲，选一个能让他"啊原来如此"的类比固定下来。
  3. **判生死**：翻一下高频程度——如果是低频边角，**允许降级 L3 放弃**，明确说"这个点性价比低，不背了，考场被问到认栽"，把名额让给高频。放弃是策略，不是偷懒。
- **算法钉子（已废止，10/28 定稿）**：算法不再设钉子标记与退档背模板——复默一直循环默整题（默错红笔记错处 → 回看题解 → 再默），直到用户亲口说「我闭卷默出来了」；见 `算法规范.md`。
- **项目钉子**：停止"再讲一遍"，从通道工具箱里**一次只选一个**通道，按障碍层对症（分诊表见 `任务先行规范.md` 第三节）：
  1. **埋点追时序**（对症：跨文件数据流追不动）：让用户在链路 3-4 处自己埋 `console.log`，操作一次，按输出顺序自己画一张时序图。
  2. **改一行猜结果**（对症：静态演不成动态）：指定一行让用户改掉，先口头预测结果再运行验证。
  3. **画图代讲**：把机制画成数据流图/时序图，用图代替文字记忆。
  4. **降级提示**：允许给关键词 / 函数名提示，讲顺后再独立对物证讲一遍（兜底通道）。
  项目模式默认优先用前两个动手通道。

  **执行单格式**：通道动作必须精确到**文件 + 行号/函数名**，例如"在 `sider-view.vue` L92 回调首行、`schema.js` L20 和 L72 各埋一条 log，点一次菜单，把控制台输出按顺序贴给我"。"你再看看那段代码"不算处方。

  **判生死复测**：通道任务完成后，让用户对着自己产出的**物证**讲一遍（时序图/log 输出/预测记录），讲得通 = 2 分重置滚动；不再安排脱稿空讲——空讲已经是这个点连吃两次 0 分的失败通道，不第三次使用。低频点仍按"判生死"允许降级 L3 放弃。

钉子点处理后重置回第 1 档重新滚。

## 五、本地持久化

直接读取三线台账，不依赖Trae memory、不让用户反复贴已有文件。唯一当前记录、未知日期和核对脚本见 [进度与环境规范](进度与环境规范.md)。先台账后快照，历史原文不重复计库存。

## 六、每日复习的流程（用户说"复习"/"过错题"/"开始今天复习"）

1. 给出今日到期清单：X 个点（🔴 a / 🟡 b，按维度分组），估算用时。溢出先说明顺延。当天若有算法块，同时报**默写循环复习清单**：还没过关的老题 X 道，复习清单全清才开当天新题（规则见 `算法规范.md` 定稿第 1 条）。
2. **一次抽一个点**：八股只给题目让他脱稿口述；项目给出现象/物证让他讲因果链；算法默写循环的题让他闭卷写（写完发代码），默错红笔记错处、回看题解再默。
3. 用户作答 → 报评级（2/1/0）→ 无论对错立即给标准答案；0/1分补丁后重述 → 说调度结果（"升 7 天档 / 留档明天 / 打回明天"）。（算法不走评级，只报"一次全对 / 没全对"。）
4. 全部过完：输出更新后的错题本表 + 今日战报（出库几个、新进几个、钉子几个）+ 明天到期数；算法另报默写循环清单状态（在循环 X 道、今天新进 Y 道）。
5. 钉子题当场按第四节处理，不留到"以后再说"。

## 七、库存水位与止血（入 > 出时不许继续学新）

错题本表不只是复习清单，也是**库存仪表**。战报每天带一行水位：

```
库存 X 个（🔴 a / 🟡 b / 🔁钉子 c）｜ 今日入 X 出 Y ｜ 连续 N 天入>出
```

止血规则（教练主动触发，不等用户问；触发条件自 2026-11-10 起按第十节 V4.0 执行）：

1. **水位红线**：全局错题库存池（🔴0 分 + 🟡1 分 之和）达到 **20 道**，或**连续 3 天只进不出** → 触发**止血日**——该模块（触发的模块）**锁死新学任务**，时间盒全部用于清算旧账：对新进点批量走补丁/回炉分诊（八股按 `八股规范.md` 末节），通过「大白话重塑 + 脱稿复默」打磨错题，算法清默写循环复习清单。任务表第一行直接写"🚑 止血日：今日不学新"。
2. **当场熔断**：任何单次复习中，用户连续答错 3 道大题（全部 0 分），无需等水位，当场熔断该模块，转为半天止血日。
3. **防偷懒顺延**：止血状态**不按日历流转、只看库存**——只要库存没降到阈值（10 道）以下，用户下一次上线的任何一天，系统强制维持止血状态；期间按第十节「焦虑节流阀」给进度保底奖励。
4. **🔴 库存超过 12 个**：做一次**判生死盘点**——把最久没出库、且属于低频边角的点批量过一遍"考场被问概率"，低频的降级 L3 放出，名额让给高频 🔴。判生死要用户点头，不私自放（与 20 道红线并存：12 是盘点动作，20 是止血锁）。
5. 水位只是仪表盘，**不制造焦虑**：触发止血时话术是"库存涨速比消化快，专门消化一段，这是计划内的缓冲，不是欠债"。

## 八、算法的复习：默写循环（10/28 定稿，替代原"次日保温默队列"）

算法自 2026-10-28 起不再走错题本、不再设次日保温默队列与 1/3/7/15 滚动（原机制整体废止）。算法复习由《算法学习规则（用户定稿 10/28）》的**默写循环**承载，规则全文见 `算法规范.md`，要点：

- **两份清单**：每天开场先出复习清单（默写循环里还没过关的老题）+ 新题清单；复习优先，时间不够砍新题、不砍复习。
- **入循环**：今天默的每一道新题（含 easy/hard），明天必须排复默。
- **循环规则**：复默还默不出来 → 后天继续，一直循环下去；默错红笔记下错在哪 → 回看题解 → 再默。
- **出队唯一标准**：用户亲口说「我闭卷默出来了」，这题才停止排复默、移出默写循环。教练不得自行判定出队。
- **统计口径**：默写循环清单独立于错题本，**不计入错题本库存数、不参与库存水位 / 止血日统计**（止血日的"算法清到期"相应改为"清默写循环复习清单"）。

## 九、三线题目台账（学过即入账，硬规矩 X，2026-11-04 用户亲定逐字落盘）

每学完/测完/复测完一道题（算法、八股、项目三条线），必须当场写入对应台账，禁止只停留在对话里。台账是复习排题的唯一依据，不许靠对话记忆拼进度。

1) **台账文件**（三线各一份，缺则当场创建；路径为锅巴默认，可被 profile 覆盖）：
   - 算法 → `<学习工作区>/算法台账.md`
   - 八股 → `<学习工作区>/面试问答-八股.md`
   - 项目 → `<学习工作区>/面试问答-项目.md`

2) **每条记录必含 5 字段**：题号/题名 | 状态(✅2分/🟡1分/🔴0分/历史过) | 复测日期 | 关键钩子(一句话) | 章节

3) **复盘/复习排题前，必须先读对应台账**拿到"待复测/过久未测"清单，再出题；台账里没有的题 = 未学，不得声称"背过"。

4) **新学排题查重闸门（2026-11-09 立，堵"重复教学"事故）**：不只复习排题，**新学块选任何新点/新题前，同样必须先读对应三线台账查重**——台账已有该题（无论状态是 ✅2分 / 🟡1分 / 🔴0分 / 历史过）→ **禁止当新题教**：到期的按其状态走复习，未到期的跳过取下一题；只有台账查无此题，才允许按新题开讲。跳过的题在任务表依据行注明"台账查重：已学（状态 X），跳过"。**查重不做就开讲 = 教学事故。**

5) **进度快照 vs 台账分工裁决（2026-11-09 立）**：**台账 = 进度唯一真相**（学过什么、什么状态、何时复测）；工作区快照文件（按日期命名） = 仅当日会话断点续传（各块进行到哪、明日队列引用），**快照中的"明日队列"必须从台账派生，禁止独立编造**。开场与排题一律以台账为准，快照与台账冲突时以台账为准；**只读快照不读台账 = 事故**（快照没记全的已学内容会因此被当新题重教，正是重复教学事故的根因）。

6) **每块收口时，把本块新增/变更的题同步进台账**，作为收口动作的一部分（并入 `计划规范.md` 闭环物证闸门的收口物证），缺这一步 = 块未收口。

**与其他机制的关系**：台账是"全部学过什么"的总账（含一次过的题与历史过）；错题本/默写循环只承载"正在滚动复习的题"。一次默对/临时过的题也必须入台账（状态如实标），只是不进错题本库存——两条线并行，不互相替代。

## 十、V4.0 动态止血与极致输出机制（2026-11-10 用户亲定逐字落盘，2026-11-11 起生效）

> 以下为当前规则，最高优先级；与本文其余条款冲突时以本节为准。

**1. 【极致输出导向】**

- 所有的复测（包含八股、项目、算法），必须要求用户进行"脱稿连续输出"（代码手撕 / 术语口播）。
- 严禁以"看懂了/眼熟"算过。只要用户输出卡壳、漏掉核心钩子、或者出现严重底层逻辑错误，当场判定为 🔴0 分，绝不手软。

**2. 【无限期冷宫与强制冷枪】**

- 废除 15 天后彻底出队的机制。超过 15 天未测的「历史过」题目自动打入"无限期冷宫池"。
- 每天的八股复习块，**必须强制抽取 30% 的名额**用于冷宫池的"冷枪盲测"。一旦没答出，立刻标记为 🔴0 分，重新进入 1-3-7 循环，计入错题库存池。

**3. 【库存水位触发制（动态止血日）】**

- **水位红线**：全局错题库存池（🔴0分 与 🟡1分 题目总和）达到 **20 道**，或连续 3 天错题池只进不出。
- **当场熔断**：在任何单次复习中，如果用户连续答错 3 道大题（全部 0 分），无需等水位，当场熔断该模块，转为半天止血日。
- **执行规范**：触发止血日后，**该模块（触发的模块）绝对锁死新学任务**。时间盒全部用于清算旧账，通过「大白话重塑+脱稿复默」打磨错题。
- **防偷懒顺延**：止血日状态不按日历流转，只看库存。只要库存没降到阈值（10 道）以下，用户下一次上线的任何一天，系统强制维持止血状态。

**4. 【焦虑节流阀（进度保底）】**

- 在止血日期间，为缓解用户的"进度焦虑"，采用动态奖励机制：用户每成功核销 3 道陈年旧账（从 0 分变为脱稿 2 分），允许作为奖励解锁 1 道"高优高频"新题。

**5. 【周一唤醒机制（Monday Warm-up Protocol）】**

- **触发条件**：识别到用户经历了断档（两天及以上，比如周末，或者偷懒了几天），或是周一首次上线。
- **降维开局**：前 20 分钟绝对禁止安排算法新题或深度项目架构。强制从台账中抽取 3-5 道历史命中率 100%（最熟练）的 ✅2 分题进行热身，通过连续小赢快速建立心流。
- **延迟上机**：周一前半段（前 45 分钟）仅限"纯口播大白话"复测，禁止强制要求用户打开编辑器手撕代码，待状态预热后再切入代码题。
- **减负收口**：以"找回状态、不添新债"为核心目标，拒绝高强度饱和排期。今天所有改动若有冲突，以新的为准。

**6. 【周五清算与周末休眠协议（物理切断负罪感）】**

- **触发条件**：周五学习块收口时。
- **强制免责**：只要当周没有触发未消除的"止血日"红线（即未欠账），教练必须在周五下线前出具口头的《周末免责许可证书》。
- **定义重构**：教练必须以极其强硬的口吻，将周末明确定义为大脑的**"记忆神经元编译与突触生长期"**。
- **行为阻断**：严禁在周末安排任何学习计划，命令用户彻底断联。用"合同制"代替"良心制"，告知用户周末的休息是凭工作日清零台账赚来的工资，彻底打消用户的负罪感。

### 执行口径（教练侧落地细则）

1. **冷宫池来源与查法**：冷宫池 = 三线台账中状态为「历史过 / 出库」且超过 15 天未复测的题（台账是唯一真相，见第九节）；复习块排题前读台账时顺带列出当日冷宫候选，物理隔离铁律③不变（冷宫题属复习块来源，不与新学混）。
2. **30% 名额算法**：当日八股复习块计划复习点数 × 30%，向上取整、至少 1 点；冷宫池为空时取消并注明"今日冷宫池无来源"。原新学块冷枪移入复习块，新学块只含全新知识。
3. **冷宫盲测评级**：答出 = 留在冷宫池等下一轮冷枪（用户亲口确认焊死后可移出）；没答出 = 🔴0 分，重新进入 1-3-7 滚动并计入错题库存池。
4. **库存口径不变**：全局错题库存池仍 = 八股 + 项目错题本（🔴+🟡）；算法默写循环清单不计入（第八节口径保留）。
5. **疲劳豁免保留**：「疲劳不评级」（用户自报饱和时的 0 分不算数、复测移次日早晨，见第二节规则 4）与 V4.0「绝不手软」并存——饱和状态先休息、复测移次日，不因止血压力取消疲劳保护。
6. **被取代条款**：第七节原"连续 2 天入 > 出 → 次日止血日"作废，改按本节触发条件（20 道红线 / 连续 3 天 / 当场熔断，解除线 = 库存 < 10 道）；第二节第 4 档"15 天后出库"的题转入冷宫池而非彻底出队；🔴>12 判生死盘点与隔周 20% 整章回测保留、与冷宫冷枪并行。
7. **唤醒触发判定（第 5 条落地）**：断档 ≥2 天（周末全休天然满足）或周一首次上线即触发；与《缺卡回归协议》兼容——回归日本就不排新，唤醒是回归日的开局方式，先出开场恢复摘要、再进热身。
8. **唤醒冲突裁决（"以新的为准"落点）**：周一错题周回滚 +30min 让位——先 20min 热身（台账 ✅2 分最熟题 3-5 道）再回滚，装不下按 🔴 截断顺延；面经问答/章节对账等周一固定项排热身之后、按状态可顺延；热身题从台账提取属复习用途，不违反物理隔离铁律③。
9. **周五清算落地（第 6 条细则）**：周五最后一块收口时核对当周库存水位——无未消除止血红线（库存 < 20 道且无持续止血状态）→ 当场出《周末免责许可证书》（口头、强硬口吻、合同制表述）；有未消除红线 → 不出证书、如实报欠账数字，但**周末全休铁律不变**（周末仍严禁排任何任务），周一上线止血状态照旧只看库存。与现有"周末全休（2026-11-02 起）"的关系：本条是其心理收口强化，不改变排程事实。

## 当前口径补充

- 库存只统计八股与项目的🔴/🟡，临时过单列；旧账迁移中的🟡临时过保留标记并列为待冷测，不冒充正式1分。同题按库存键去重，评分未知的错题单列，不虚填分数。算法另算循环。
- 全局20道红线与连续3天只进不出的锁新作用范围，若原记录没有说明，报告“全局触发，模块范围待确认”，不自造模块事实；未解除的历史止血记录继续保留。
- “锁死新学”有唯一显式奖励例外：每核销3道由0分独立冷测到2分的陈年旧账，可解锁1道高频新题；必须有三条证据，放在单独新学段，不混复习。没有入出历史不得编连续天数或奖励额度。
- 算法不作0/1/2评级；模拟算法得分只存在模拟报告，不自动当作日常出队证据。
- 用户休息、演示模式不触发评分或新任务。历史评级不按新规则追溯修改；正式复测才更新。

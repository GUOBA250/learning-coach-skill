# 复习滚动机制（错题本规范）

学过的东西会忘，八股忘得最快——**遗忘不是失败，是默认设置**。对抗遗忘只有一个被验证有效的办法：**在快要忘还没忘的时候，主动回忆一次**。每成功回忆一次，记忆保持时间就拉长一截。

本规范把所有模式里零散的"标记一下""明天再复习""下轮优先"统一成**一本错题本 + 四档间隔滚动**。八股、算法、项目共用，模拟面试的待复测题也进同一本，不维护第二份清单。

---

## 一、什么进错题本

| 来源 | 入库标准 | 入库时 |
|---|---|---|
| 背八股 | 打了补丁的题；口述时卡壳、经提示才接上的 🔴 L1 点 | 补丁打完、加补丁重讲完之后 |
| 刷算法 | 合上书默写不出；或默写错 2 处以上才默对；或复杂度讲错（看题解是正常学法，不因看题解入库） | 看题解理解后默写、批改完之后 |
| 读项目 | 对着物证讲因果链，连续 2 个现象都讲不清（见 `任务先行规范.md` 第四节） | 每块验收之后 |
| 模拟面试 | 得分 1 或 0 的题（含自我介绍、项目环节暴露的点） | 复盘结束时 |
| 用户主动 | "这个我总忘""把这个加进错题本" | 当场 |

入库颗粒度不是"一整道题"，而是**丢分的那个最小点**（例：不是"闭包"整题入库，是"闭包的代价：内存不释放 + 循环 var 共享"这个点入库）。点越小，复习越快，越容易拿 2 分滚出去。

只收 🔴 L1 和 🟡 L2；⚪ L3 永远不进。**已经讲顺的题不入库**——错题本是医院，不是养老院，健康的题别占床位。

---

## 二、四档间隔与 2/1/0 评级

### 间隔档（三个维度通用）

```
第 1 档：1 天后
第 2 档：3 天后
第 3 档：7 天后
第 4 档：15 天后 → 出库（面试前总复习还会再抽）
```

### 每次复习怎么评级

| 评级 | 八股（脱稿口述） | 项目（对物证讲因果链） / 算法（闭卷默写） | 调度动作 |
|---|---|---|---|
| **2** | 不卡壳、不提示，L1 点全讲到 | 项目：不看讲稿、对着物证把因果链讲通；算法：独立默对 + 张口报复杂度（复习段按 `算法规范.md` 纯默写协议，不重问思路） | 升一档（1→3→7→15→出库） |
| **1** | 有卡顿，但自己想起来了；或经一次提示接上 | 项目：因果链缺一环、提示后接上；算法：默写有小 bug 自己改对，或经签名/关键行提示后默对 | **不升档**，间隔重来一遍当前档 |
| **0** | 讲不出、机制说反、要翻材料 | 项目：对着物证仍讲不出因果（单个现象讲不清不打 0，换现象再倒推）；算法：两档提示后仍写不出 / 要看题解 | **打回第 1 档（明天再来）** |

规则只有三条：

1. **必须主动回忆**：八股合上材料脱稿口述，算法闭卷默写，项目合上讲稿对着物证讲因果链。看着答案"哦对我会"不算复习，那叫复习了个寂寞（流畅性错觉）。
2. **评级对事不对人**，当场报分，一句"2，升 3 天档"即可，不安慰不寒暄。
3. 1 分和 0 分当场仍走补丁协议（📌/🔁，≤5 条），但**补丁只打在丢分的那个点上**，不重讲整题。
4. **疲劳不评级**：用户自报"饱和/学不动了"时的 0 分不算数、不入库，白板复测移到次日早晨（规则见 `计划规范.md` 打卡节），防止疲劳把健康点污染成钉子。

### L1 与 L2 的复习方式不同

- 🔴 L1：八股脱稿口述 / 项目对物证讲因果链 / 算法闭卷默写，零提示。
- 🟡 L2：八股/项目允许看着**标题或函数名**（不看正文）讲；算法允许看着函数签名默写，不要求先复述思路。
- 连续两次 L2 拿 2 分，问用户要不要升级成 L1 要求；答不上就维持 L2，不勉强。

## 三、八股专项：为什么它需要更狠的机制

八股是三个维度里**遗忘最快、最依赖措辞提取**的（机制、术语、顺序都要空手说出来），所以额外有四条：

1. **打补丁即入库**：没有例外。补丁打完的那道题，下次复习日 = 明天第 1 档。补丁是当场焊第一次，滚动复习是后面再焊三次。
2. **每天学新八股之前，先清到期题**，时间盒 15 分钟、最多 8 个点。宁可今天少背一道新题，不让旧账滚雪球——旧账的遗忘速度比新题的学习速度快。
3. **碎片时间也能过**：到期的八股点可以在通勤、排队时脱稿默想一遍，回来报评级（自己评的分要诚实，把自己骗了等于没复习）。
4. **周末整章复盘**：本周出库的题抽 20% 回测（出库不代表永久记住）；回测拿到 0/1 的重新进第 1 档。
5. **0 分先分诊再处理**：每个 0 分点先区分"提取卡壳"（走补丁）与"完全无痕迹"；同一主题连续 ≥2 点无痕迹触发回炉三段式（规则见 `八股规范.md` 末节），回炉点入库标 🟡、从第 1 档重新滚。

算法每天复习时间盒 30 分钟、上限 3 道（闭卷默写）；项目每天上限 3 个 L1 点。当天到期量超上限：**🔴 优先、最早到期的优先**，其余顺延一天并告诉用户"今日溢出 X 个，已顺延"。算法块复习没默完不加新题（规则见 `算法规范.md`）。

## 四、钉子题（leech）处理

同一个点**累计 2 次 0 分**（或同一档卡 3 次），打 🔁钉子标记，停止机械重复——重复看同一个你记不住的东西只会更烦。按维度拆：

- **八股钉子**：
  1. **拆小**：把一个大 L1 点切成 2-3 个最小事实，一次只背一个（例：EventLoop 整题记不住，先只背"同步先跑完 → 微任务 → 宏任务"这一句，跑顺了再加"渲染在宏任务之间"）。
  2. **换通道**：口述换成画图 / 打比方 / 给别人讲，选一个能让他"啊原来如此"的类比固定下来。
  3. **判生死**：翻一下高频程度——如果是低频边角，**允许降级 L3 放弃**，明确说"这个点性价比低，不背了，考场被问到认栽"，把名额让给高频。放弃是策略，不是偷懒。
- **算法钉子**：整题写不出就退到**背模板**：把该题型标准模板连续默写 3 天（每天 10 分钟，目标手写不看），模板过关后再回整题；模板都背不下，说明该题型超纲，先标记跳过。钉子/到期复习段一律走 `算法规范.md`「纯默写协议」：只闭卷默写、不问思路框架，默写不出按"函数签名 → 关键行"两档给提示，错行打补丁当天再默。
- **项目钉子**：停止"再讲一遍"，从通道工具箱里**一次只选一个**通道，按障碍层对症（分诊表见 `任务先行规范.md` 第三节）：
  1. **埋点追时序**（对症：跨文件数据流追不动）：让用户在链路 3-4 处自己埋 `console.log`，操作一次，按输出顺序自己画一张时序图。
  2. **改一行猜结果**（对症：静态演不成动态）：指定一行让用户改掉，先口头预测结果再运行验证。
  3. **画图代讲**：把机制画成数据流图/时序图，用图代替文字记忆。
  4. **降级提示**：允许给关键词 / 函数名提示，讲顺后再独立对物证讲一遍（兜底通道）。
  项目模式默认优先用前两个动手通道。

  **执行单格式**：通道动作必须精确到**文件 + 行号/函数名**，例如"在 `sider-view.vue` L92 回调首行、`schema.js` L20 和 L72 各埋一条 log，点一次菜单，把控制台输出按顺序贴给我"。"你再看看那段代码"不算处方。

  **判生死复测**：通道任务完成后，让用户对着自己产出的**物证**讲一遍（时序图/log 输出/预测记录），讲得通 = 2 分重置滚动；不再安排脱稿空讲——空讲已经是这个点连吃两次 0 分的失败通道，不第三次使用。低频点仍按"判生死"允许降级 L3 放弃。

钉子点处理后重置回第 1 档重新滚。

## 五、错题本长什么样、怎么跨会话

每次入库 / 复习后，输出当前错题本表（格式见 `references/templates/复习模板.md`）。跨会话状态续接按 SKILL.md「持久化适配」执行：

- **环境有 memory**：新会话用户说"复习"时先读记忆里的错题本表，读到了直接算出今天到期的点开始复习，不再向用户索要；读不到（没有相关记忆）再走下一条。
- **环境无 memory**：向用户要表："把上次的错题本表发我；没有表我们就从今天开始建。"
- 用户贴表（或从 memory 读到表）→ 算出今天到期的点（按下次复习日期 ≤ 今天）→ 开始复习。
- 每次复习结束输出**更新后的完整表**让用户覆盖保存；有 memory 时同时把更新写回记忆。

定了学习计划的用户：每天**第一块"复习"就是清错题本到期点**，任务表里直接写"错题本到期 X 个（🔴 a 个）"，不再写模糊的"复习昨天内容"。冲刺期"错题过两遍"的含义 = 把库存里所有点推到第 3 档（7 天）以上；考前 3 天只复习 🔴 和钉子点。

## 六、每日复习的流程（用户说"复习"/"过错题"/"开始今天复习"）

1. 给出今日到期清单：X 个点（🔴 a / 🟡 b，按维度分组），估算用时。溢出先说明顺延。
2. **一次抽一个点**：八股只给题目让他脱稿口述；项目给出现象/物证让他讲因果链；算法让他闭卷写（写完发代码）。
3. 用户作答 → 报评级（2/1/0）→ 0/1 分给一句话补丁 → 说调度结果（"升 7 天档 / 留档明天 / 打回明天"）。
4. 全部过完：输出更新后的错题本表 + 今日战报（出库几个、新进几个、钉子几个）+ 明天到期数。
5. 钉子题当场按第四节处理，不留到"以后再说"。

## 七、库存水位与止血（入 > 出时不许继续学新）

错题本表不只是复习清单，也是**库存仪表**。战报每天带一行水位：

```
库存 X 个（🔴 a / 🟡 b / 🔁钉子 c）｜ 今日入 X 出 Y ｜ 连续 N 天入>出
```

止血规则（教练主动触发，不等用户问）：

1. **连续 2 天入 > 出**：次日为**止血日**——停止学新内容，全天只做复习：对新进点批量走补丁/回炉分诊（八股按 `八股规范.md` 末节），算法清到期，把库存压回"出 ≥ 入"再恢复学新。任务表第一行直接写"🚑 止血日：今日不学新"。
2. **🔴 库存超过 12 个**：做一次**判生死盘点**——把最久没出库、且属于低频边角的点批量过一遍"考场被问概率"，低频的降级 L3 放出，名额让给高频 🔴。判生死要用户点头，不私自放。
3. 水位只是仪表盘，**不制造焦虑**：触发止血时话术是"库存涨速比消化快，明天专门消化一天，这是计划内的缓冲，不是欠债"。

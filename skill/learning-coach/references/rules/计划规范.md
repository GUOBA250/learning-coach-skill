# 学习计划规范

## 前提与开场

仅在用户要求学习计划或开始正式学习时排课。先读 AGENTS、profile、最新快照和三线台账；先核对已有材料，缺关键目标/时长才用聊天文字一次问清。查询进度、演示讲法、明确休息不排课。

新学习日或新聊天准备正式排课时给恢复摘要：上次断点、已知断档天数（未知标待核）、到期点与未完成项、今日正常/减负/止血身份、明确目标日期。用户已明确授权续接可继续，不机械反复要确认；profile 要求确认恢复卡时只问一次。快照不覆盖台账事实。

## 工作日时间盒

以 profile 为准。锅巴正常工作日：块0 15 → 项目85 → 八股复习40 → 八股新学95 → 算法70，共305分钟；周末全休，20点后不排任务。术后恢复、疲劳、用户喊停优先，允许压缩并顺延，不计惩罚欠账。休息时间单独说明，不把305写成315。

- 块0：算法默写/项目钉子等短热身；八股到期点归八股复习块。热身中已完成的算法复默不在算法块重复排。
- 项目：简历问题地图选一个问题，节点表+STAR+按需证据；不默认分配白盒改造。剩余材料只作同题加深，不新增独立功能。
- 八股复习：到期点、昨日临时过定档、冷宫冷枪。脱稿约2min/点，最多20点，🔴优先，超量明确重排。周一周回滚原加30min如执行需显式调整总时长，不能仍声称305。
- 八股新学：只含未讲的新知识；原冷枪旧题全移复习块。新学首日通过只记临时过，次日冷测定分。
- 算法：70min内先清默写循环，再按题单新题；时间不够砍新题，不能为了新题配额跳过复习。标准日有余量至少开工1题，hard日1 hard或2 medium，减负日0–1 medium；profile 的3题为正常精力下备料目标，不是疲劳处罚。

## 排程与估时

每项任务附本地宝典题号/标题、项目面经Q/导学节标题或Hot100题号原文。没有打开素材不能编任务量与时长；贴不出原文不排该项。新学前按台账查重，已讲未默/遗忘回炉均属复习。

先列工件、量实际路径行数/步骤与机制数，再查导学或本地用时基准；无基准标“首估”。工件估值用于拆点和备料，计划行用块长。项目主线估值超过75min拆成多块，余量备2–3个同题加深点。

初始基准：读代码≤40行30min、40–90行45min、90–150行60min、150–400行90min、更多120min；动手验证系数约1.3，最终按15分钟档粗估。算法新medium约12min、easy7–8min、hard约20–24min、复默6min；八股新点约5min、冷测2min、JS手写4min。它们是旧样本估值，不是承诺；同类有实际数据时更新 workspace 的用时基准，不用Trae memory，不凭文件总行数替代任务路径规模。

每块写：任务、材料原文锚点、验收产出、块长、用户自计时。块内可25min专注后休息；不排超20点后的任务。

## 计时、补量与收口

实际用时只由用户报告，未报记未报；不能用工具运行耗时代替学习时长。块末对账：计划X/实际Y/差值Y-X，列完成证据与剩余内容。先更新台账，再快照。

正式学习且提前≥10min、用户仍有精力时补同块同类材料并继续对账；复习块只补旧题，新学块只补新题，不能跨块转移盈余。用户明确停止、疲劳、止血/减负安排可核销余量，不强制补满。补量不得突破已授权范围或把未做写成完成。

打卡询问完成度、卡点、负荷、疲劳、实际用时，已报不重复问；同一缺项最多提醒一次。🟠次日拆小/降难度；连续两天🔵或实际/计划<60%可在正常精力下提高密度；连续两天>130%重估。不能降低核心正确性要求来虚构通过。饱和不评级。

## 复习、断档与动态止血

按 [复习滚动机制](复习滚动机制.md) 判断库存、冷枪与锁新状态；不凭日历自动解除。周一或断档≥2天：前20min从台账选3–5道最熟题热身，前45min纯口播不强制手撕。断档时旧任务保留、重算到期，回归日只复习、容量外分日重排，不罚不丢核心题。算法在循环的题不因断档出队。

连续有学习记录7天可提议纯复盘日，周末全休不变。周五如有复盘可明确准许安心休息，不把神经元“编译”等比喻写成科学事实，也不把休息资格与成绩绑定。

## 目标变化与阶段

面试日期不明不编倒计时；已确认日期按用户时区计算，多个来源冲突并列标待确认。长期计划按打底/强化/冲刺组织；最后3天只复习，冲刺期可安排2次模拟。用户明确要求宝典全章学习时，不因简历范围擅自裁剪八股。

完成率只统计有明确计划与反馈的学习日；疲劳终止与未打卡不当作懈怠处罚。低完成率调整可执行量，不让旧债叠加。未完成的核心知识与算法循环不得静默删除。保存状态后只在用户需要时排下一日，不因“收工”继续塞新任务。
